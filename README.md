# Vida em Equilíbrio - Frontend

Plataforma web de acompanhamento de saúde mental, desenvolvida para conectar psicólogos e pacientes.

## Sobre o Projeto

O **Vida em Equilíbrio** permite que psicólogos acompanhem o estado emocional de seus pacientes através de relatos diários e registro de humor, facilitando o acompanhamento terapêutico de forma digital e acessível.

## Como Executar

### Pré-requisitos
- Node.js (v16+)
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone <url-do-repositorio>

# Entre na pasta
cd vida-em-equilibrio-front

# Instale as dependências
npm install

# Configure a API
# Edite src/services/api.js e ajuste a URL do backend
```

### Executar

```bash
# Ambiente de desenvolvimento
npm start

# Acesse: http://localhost:3000
```

## Funcionalidades

### Psicólogo
- Cadastro de novos pacientes
- Visualização de relatórios de humor
- Exportação de dados em CSV
- Dashboard com calendário de humor

### Paciente
- Registro diário de relatos
- Seleção de humor com emojis
- Visualização de calendário pessoal
- Configuração de avatar
